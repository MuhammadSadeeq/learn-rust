The Forge

Reading builds recognition; writing builds skill. The Forge runs in your terminal next to your editor.

  1. Install Rust with rustup: one command on macOS and Linux, one installer on Windows. Chapter 01 walks you through it.
  2. Clone this repository and open it in VS Code with rust-analyzer (or RustRover).
  3. Run cargo forge in the repo. It finds your next quest, recompiles on every save, and moves on when the tests pass. Stuck? cargo forge hint.

Each chapter ends with its quests. Mark them passed on the chapter page to light up the route here.
