How to read any rustc error

Every rustc error has the same parts, in the same order. Read them from the top, and the message usually tells you what to change.

  1. 1
    Code and summary

    The code, such as E0382, is what you search for. The text after it says what went wrong.

  2. 2
    Location

    The arrow gives the file, line and column of the main problem. Start there.

  3. 3
    Primary span

    The ^^^ marks the exact expression rustc blames. This is usually the line you change.

  4. 4
    Secondary spans

    The --- lines mark other places that matter, such as where a value was moved or where a borrow began.

  5. 5
    Notes and help

    note explains the rule. help often shows a fix as a diff, with + for added text. Read it before you apply it, because a suggestion may only silence the error.

  6. 6
    The explain command

    rustc --explain E0382 prints a longer explanation, with examples, offline. Cargo shows the same errors, so the command works in any project.
