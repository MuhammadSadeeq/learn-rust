Ownership Story

The Memory X-Ray, acted out. Every crab is a variable, every fluffy is a value on the heap, and the leash between them is the pointer. Watch who holds the leash.

Crab = a variableIt sits in its function's tide pool on the stack. Small values like an i32 ride in its claw.
Fluffy = a heap valueThe bytes of a String or a Vec. It lives as long as someone owns it.


Leash = a pointerRope: owner. Dotted: & borrow. Locked: &mut.
The Inspector = the borrow checkerStamps an error code on a crab that breaks a rule, before the program ever runs.
Oxi = your guideNarrates each step and asks you to predict the next one.

Every program here is a real Memory X-Ray scenario from the chapters. Press Diagram to see the same step as the classic X-Ray, and use ← → to step once the story has focus.
